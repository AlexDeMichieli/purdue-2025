# Lesson 06 Demo 01 - JSON Example

## Run the Example

```bash
cd /Users/alexanderdemichieli/Desktop/purdue-2025/SQL/lesson_6/examples
node json_example.js
```

## Expected Output

```json
{
    "name": "John",
    "age": 30,
    "city": "New York"
}
```

## What This Demonstrates

- Creating JSON objects in JavaScript
- Adding fields (strings, numbers, arrays, nested objects)
- Converting objects to JSON strings with `JSON.stringify()`
- Parsing JSON strings back to objects with `JSON.parse()`
- BSON-like document structure used by MongoDB
